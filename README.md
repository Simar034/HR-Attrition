# HR Analytics Project - Employee Attrition Prediction

This project analyzes HR data to predict employee attrition using multiple machine learning models.

## 📁 Structure
- `scripts/hr_attrition_analysis_basic.py` - Logistic Regression, Decision Tree, Random Forest, SHAP
- `scripts/hr_attrition_analysis_advanced.py` - Adds Neural Network + LIME explainability
- `requirements.txt` - Python dependencies
- `visuals/` - Generated charts/plots
- `data/` - Datasets (if used)

## ▶️ Run
```
pip install -r requirements.txt
python scripts/hr_attrition_analysis_basic.py
python scripts/hr_attrition_analysis_advanced.py
```
